### 1) Programmazione con Python:

Padronanza della Sintassi: Scrivere codice Python corretto utilizzando variabili, operatori e tipi di dati fondamentali.

Modularità: Progettare funzioni riutilizzabili per organizzare il codice in modo efficiente e leggibile.
Risoluzione di Problemi: Sviluppare la capacità di tradurre un'esigenza logica in uno script Python funzionante e privo di errori.
